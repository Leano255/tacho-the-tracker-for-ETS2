# TACHO — the tracker for ETS2

TACHO automatically records your jobs in Euro Truck Simulator 2 and American Truck Simulator. It is like Volanta, but for trucks.

## Features

- **Live map** of your truck, drawn from your own game files so it matches the game 1:1
- **Map filters** for fuel stations, services, parking, weigh stations, dealers, garages, ferries and more
- **Automatic logbook** of every delivery: route, distance, cargo, income, damage and fuel
- **Statistics, garage and achievements**
- **Built-in updater**: Options → "Nach Updates suchen" downloads and installs new versions

## Install

1. Download `TACHO-x.y.z-Windows.zip` from [Releases](https://github.com/Leano255/tacho-the-tracker-for-ETS2/releases/latest).
2. Unzip it anywhere, for example to `Documents\TACHO`.
3. Start `TACHO.exe`. On first launch, TACHO installs the telemetry plugin into your game.
4. Start the game and drive.

Requirements: Windows 10/11 with Microsoft Edge WebView2 (preinstalled on most PCs).

The interface is in German for now. An English version is coming.

## Updates

Once installed, TACHO checks this repository for new releases. You don't need a GitHub account.
